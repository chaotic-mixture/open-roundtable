# Reference materials

The project has a local-only `private/` evidence archive containing the original design discussions. It is excluded from Git, packages and publication. It is not licensed for redistribution by the project's MIT license.

Original user propositions, third-party assistant proposals and current engineering choices must be kept distinct. The charter is the public-facing paraphrase; source attribution and exact original messages remain in the private archive. External technical references and adoption boundaries are in `docs/OPEN_SOURCE_LANDSCAPE.md`.
